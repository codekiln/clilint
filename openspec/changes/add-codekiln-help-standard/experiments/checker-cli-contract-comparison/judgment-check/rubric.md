# First-task clarity rubric

Judge how directly the README helps a new user complete one useful first task.

- `0.0`: The README gives no usable first task.
- `2.0`: The README names a command but leaves important steps unexplained.
- `4.0`: The README gives a focused, complete first task with the expected
  result.

Fractional Scores describe evidence between the examples. A Score below `4.0`
must include at least one Check Message that explains what could improve.
